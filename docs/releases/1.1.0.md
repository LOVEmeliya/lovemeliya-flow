# LOVEmeliya Flow 1.1.0

首个公开开源版本：原生 macOS 音视频转换工具，内置本地 MCP，让 AI 和 APP 共用转换队列。

## 功能

- MP4、HEVC、WebM、MP3、M4A、WAV、FLAC 转换，以及 MP4 / MKV 换封装。
- 批量队列、截取、压缩、硬件编码、进度、取消和 FFmpeg 引擎管理。
- 七个 MCP 工具：能力查询、媒体检查、方案预检、提交、查询、列表和取消。
- MCP 默认关闭；显式读写目录授权，默认先在 APP 中确认执行。
- 输出不覆盖，重复提交去重，AI 断开后任务继续。

## 安装

下载 `LOVEmeliya-Flow-1.1.0-macos-arm64.zip`，解压并将 APP 放入“应用程序”目录。需要 **Apple Silicon Mac、macOS 14+**，并单独安装 FFmpeg（例如 `brew install ffmpeg`）。

发布包仅作 ad-hoc 签名，未进行 Apple 公证；可从源码自行构建。原有 1.0.x 用户的队列和设置继续保留。

MCP 配置位于侧栏 **AI 接入 · MCP**。设置读取与输出目录、启用后复制配置到支持本地 stdio MCP 的客户端。APP 移动位置后需要重新复制配置。

## 验证与限制

本地通过 25 项 Swift 测试、stdio MCP 端到端测试及 APP 确认转换流程。提供 SHA-256 校验文件。

暂不支持 Windows/Linux、远程 HTTP MCP、字幕烧录、多文件合并、目标大小压缩或 HDR 色调映射。FFmpeg 不包含在下载包中。

原创源码为 MIT 许可；第三方许可证随源码及 APP 附带。
